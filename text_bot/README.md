# Text Extractor Bot

نسخة معزولة من `ex.py` داخل مجلد مستقل، مع تخزين MongoDB ونظام إيموجيات مركزي مستوحى من بوت السيستم.

## التشغيل

```bash
cd text_bot
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python bot.py
```

## متغيرات البيئة

- `DISCORD_TOKEN`: توكن بوت استخراج النصوص.
- `MONGODB_URI`: رابط MongoDB، وهو مطلوب للتخزين.
- `MONGODB_DB`: اسم قاعدة البيانات، افتراضيًا `text_extractor_bot`.
- `TEMP_API_URL` و `GDRIVE_API_KEY`: مفاتيح الخدمات الخارجية.
- `SYNC_APPLICATION_EMOJIS`: يفعّل مزامنة Application Emojis عند الجاهزية وهو مفعّل افتراضيًا. حتى لو ضُبط على `false` ستعمل المزامنة قسرًا إذا كانت خريطة الإيموجيات المحلية فارغة، لأن بدونها ستظهر الإيموجيات العادية بدل المخصصة.

## الميزات الرئيسية

- **رسالة نتيجة Components V2:** عند انتهاء الاستخراج تُرسل لوحة واحدة تحتوي المنشن داخلها وتقرير الجودة على ثلاثة أسطر والملف نفسه داخل الرسالة عبر مكوّن `File`، مع فواصل مرئية وماركداون منسق، وعبارة (تم استخراج الفصل) مرة واحدة فقط.
- **الترجمة الأدبية (معطّلة افتراضيًا):** من `/setting` → قسم الترجمة. عند تفعيلها يُعاد إرسال ناتج الاستخراج إلى Qwen في مرحلة ثانية نصية فقط (بدون صور) ببرومبت ترجمة أدبية مخصص يُعلّمه أن هذا فصل مانهوا وكل سطر فقاعة حوار مستقلة فلا يدمجها، ثم يصلك ملف ثانٍ مترجم بجانب الأصلي مع إمكانية اختيار لغة الترجمة.
- **فاصل الصور ثابت:** نص كل صفحة يبدأ بسطر `## اسم الصورة` — حُذف خيار الترقيم والقالب المخصص نهائيًا.
- **المؤثرات الصوتية معطّلة افتراضيًا:** البوت يتجاهل الأصوات والكلمات الجانبية ما لم يفعّلها المستخدم من الإعدادات.
- **لوحة إعدادات علنية بأقسام:** `/setting` يعرض لوحة Components V2 على شكل صفحات: الرئيسية + الاستخراج + الترجمة، مع سيلكت منيو لاختيار القسم وزر رجوع وشرح لكل خيار.
- **دليل شامل:** `/help` أو `!مساعدة` يشرح كل أمر بدقة: ما هو، كيف يعمل، وخطواته بالترتيب.

## الإيموجيات

يعتمد بوت استخراج النصوص على الملفات الثنائية الموجودة في:

```text
text_bot/assets/emojis/
```

عند التشغيل يرفع هذه الملفات كـ Application Emojis لتطبيق بوت استخراج النصوص (بادئة النسخة الذهبية `y_`) ثم يحدّث جدول الإيموجيات المحلي `text_bot/utils/emojis.json` مع تخزين `__application_id__` للتحقق من الملكية. الإيموجيات التي تنتمي لتطبيق آخر تُرفض عمدًا لأن ديسكورد سيعرضها كنص مثل `:b_settings:` بدل رسمها — وهذا هو سبب ظهور الإيموجيات العادية سابقًا.
